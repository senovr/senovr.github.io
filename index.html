content-fabrica

A personal, local-only automation tool that produces and publishes videos to the owner's own YouTube channel ("AI in OnG"): topic research, scripting, rendering, and upload scheduling via the YouTube Data API v3 and YouTube Analytics API v2.

The app stores no user data on any server; OAuth tokens remain on the owner's machine. It does not generate or process AI NCII content.
